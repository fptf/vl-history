# Данные проекта: состав, источники, условия использования

Этот репозиторий содержит код (см. [LICENSE](LICENSE)) и **данные разных происхождений**.
Условия по данным — ниже; полная карта происхождения с датами и способами получения —
[03_sources/provenance.md](03_sources/provenance.md), сырые выгрузки сверяются по sha256
([манифест](03_sources/raw/MANIFEST.md)).

## 1. Геометрия улиц и мысов

- **Источник:** OpenStreetMap, © участники OpenStreetMap, лицензия **ODbL**.
- Получены через открытый проект [vvmap](https://github.com/skirienko/vvmap).
- **Условия публикации производных карт:** атрибуция «© участники OpenStreetMap» обязательна.
- ⚠️ У репозитория vvmap нет явной лицензии — перед коммерческим использованием уточнить у автора.

## 2. Годы присвоения названий (`year_source` у каждой линии)

- **Источник:** проект vvmap (история переименований: справочник 1924 г., списки 1957 г.,
  постановления администрации г. Владивостока и др.).
- У каждой линии есть ссылка на первоисточник года. year_source отсутствует у 77 из 821 линий (9,4 %).

## 3. Классификация названий (группа/тематика/подтема)

- **Авторская разметка** владельца проекта + вердикты веб-исследования с публичными
  URL-источниками (`06_research/findings*.jsonl` — у каждого «опознан» есть ссылка).
- 37 названий помечены «нужна проверка» — не считать официальным справочником.

## 4. Дома (слой «Дома (год постройки)»)

- **Источник списка и характеристик:** Фонд капитального ремонта Приморского края —
  [fkr25.ru](https://fkr25.ru), файл «Электронная база данных.xls» (приложение к постановлению
  Администрации ПК от 31.12.2013 № 513-па; редакция 30.04.2026).
- **Координаты:** в первоисточнике их нет; получены автоматическим геокодированием сервисом
  Фарпоста (внутренний сервис). ⚠️ **Координаты не являются официальными координатами ФКР**;
  точность не гарантируется (3,9 % домов без сопоставления с улицами карты).
- ⚠️ Явной лицензии на fkr25.ru нет; данные — приложение к нормативному акту (публичные
  госданные), статус перепубликации не проверен. Используйте на свой риск, ссылка на источник
  обязательна.
