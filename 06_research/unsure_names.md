# Веб-исследование 85 названий «нужна проверка» (V2)

Дата: 2026-11-13. Вход: `02_data/streets_classification.csv` — 85 строк с Уверенность != «высокая» (i — позиция в выгрузке, см. `06_research/findings.jsonl`; там же полные вердикты в machine-readable виде). Город: Владивосток.

## Метод

- По каждому названию 3–6 веб-запросов на русском («улица <Фамилия> Владивосток», «<Фамилия> Владивосток улица названа в честь», «<Фамилия> <должность>», цитаты книги Стратиевский О.Б., Мизь Н.Г., Авдуевская И.А. «Кто в имени твоём. Улицы г. Владивостока» (2008)).
- Основные сработавшие источники: vladnews.ru, ru.wikipedia.org, cdt-vlad.ru (список «30 улиц имён героев»), vladlib.ru, warheroes.ru, vestiprim.ru, patrokl.info, argumenti.ru, to-ros.info, kfss.ru (список переименований улиц), bezformata.com, mir24.tv, maxnest/yarodom.livejournal.com, gazetaeao.ru; для военных — «Подвиг народа»/«Открытый список» (напрямую не открылись из сети агента, факты подтверждены через Википедию/прессу).
- Верификация: каждая страница-источник открыта и проверена программно (наличие фамилии/названия и связки «улица/назван/имен…»); страницы, закрытые для прямого HTTP, проверены в браузере (LiveJournal, gazetaeao.ru). Слабые вердикты понижены (Часовитина — до «предположительно», Августовского — до «не найдено»); заменены мёртвые источники (Авраменко, Сафонова, Филипов).
