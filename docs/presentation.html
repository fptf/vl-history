С чего всё началось

Один вопрос из диалога: «почему улица
называется так?»

13 ноября 2026 в исследовательском диалоге по открытым данным vvmap собрали 820 улиц Владивостока с годами названий.

Классификации не существовало — были списки. Задача выросла из вопроса: раскрасить город по причинам названий — кто и что стоит за каждым именем.

Какую аналитику пришлось провести
×2Две волны веб-исследования 85 имён — Википедия/Ruwiki API, краеведение (vlparki, patrokl, to-ros, gazetaeao), Wikimapia только как UGC-указатель. Закрыто 48, у каждого вердикта URL-источник.
97%Дома ФКР: 11 639 по краю → 3 798 по городскому округу → 3 583 на карте; сопоставление с улицами 97,1 %, координаты — через внутренний геокодер, честно оговорено в provenance.
OSMГеометрия сверена с эталоном: все 10 «улиц в море» оказались вершинными копиями OSM на суше (PIP + пиксельный анализ + спутник Esri) — иллюзию вылечил слой воды из natural=coastline.
0Аудит приватности: секретов в истории нет; домены, Jira, диалоги вычищены перезаписью истории, проверено свежим клоном с GitHub.
