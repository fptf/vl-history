# Происхождение данных (карта источников)

Дата составления: 13.11.2026. Принцип: по каждому файлу данных указано — источник (URL / организация / «выгрузка владельца»), дата получения, лицензия/условия, способ получения (вручную / скрипт `05_code/…`). Сырые выгрузки лежат в репо и сверяются по sha256: `03_sources/raw/MANIFEST.md`, машинная проверка — `sha256sum -c 03_sources/raw/SHA256SUMS` из корня репозитория. Файловый уровень (источник → что взято → лицензия) продублирован в [sources.md](sources.md).

Даты для файлов, полученных в основном диалоге проекта (ginfo, vvmap, классификация), — по первому коммиту репозитория 13.11.2026 (c147d4a); точное время суток не фиксировалось. Ничего не перемещается и не переименовывается: манифест только ссылается на файлы там, где они лежат.

## Происхождение по полям (ключевые наборы)

### 1. Год названия улицы
- **Значения года** (`streets_map.geojson` → properties.year; в данных карты поле `y`): из выгрузки открытого проекта **vvmap** (github.com/skirienko/vvmap), файл `02_data/vvmap_streets_years.csv` (колонки street;year;description;source). Внутри vvmap годы собраны из истории переименований: справочник 1924 г., список 1957 г., постановления администрации г. Владивостока и др.
- **Построчная ссылка на документ** — properties.year_source в streets_map.geojson (текст ссылки: постановления администрации/главы г. Владивостока с номерами и датами, «Упомянута в справочнике 1924 г.», «в списке 1957 г.», ссылки t.me/vvtopo, t.me/ochkuryvl, wikimapia и т.п.).
- **Честно:** из 821 линии year_source пуст у **77** (9,4 %); полностью без года — 1 линия. У скольких линий год отсутствует вовсе — см. сводку сборки prep.py.
- «Год постройки» дома — другое поле из ФКР-выгрузки (см. п. 4), к топонимике отношения не имеет.

### 2. Геометрия
- Линии улиц и точки мысов — **OpenStreetMap** через проект vvmap; условия: ODbL, атрибуция «© участники OpenStreetMap». У репозитория vvmap явной лицензии нет — перед публикацией уточнить у автора.
- Путь в проект: `02_data/vvmap_*.csv/geojson` → `02_data/streets_map.geojson` → `05_code/prep.py` → `05_code/data.json` → шаблон → HTML.

### 3. Классификация (группа / тематика / подтема)
- **Авторская разметка**, сделана вручную в диалоге 13.11.2026 (<private-workdir>/dialog.md); эталон хранится в списках `05_code/classify.py`, дублируется в `02_data/streets_classification.csv` (обе копии поддерживаются синхронно), в карту попадает через properties/rows.json.
- **Правки:** применены все 40 вердиктов «опознан + высокая» из веб-исследования V2 (`06_research/findings.jsonl`, у каждого URL источника): 20 с переносом тематики/подтемы, 20 — подтверждение текущей (V5, 13.11.2026).
- **«нужна проверка» на момент коммита V8:** **45** названий в CSV (из 820), **44** линии в geojson (из 821 — часть названий лежит на нескольких линиях).
- Отметка об авторности есть в README и xlsx; классификация — не официальный справочник.

### 4. Дома (слой «Дома (год постройки)»)
- **Список домов и ремонтные поля** — fkr25.ru (ФКР Приморского края), «Электронная база данных.xls», приложение к Постановлению Администрации ПК от 31.12.2013 № 513-па; редакция сервера 30.04.2026, скачано 13.11.2026. SHA256 исходника: 9a3d5179… (03_sources/raw/fkr25/provenance/fkr_fkr25.xls). 11 640 адресов источника → 11 639 строк CSV (удалена только дубль-строка шапки; данные не фильтровались).
- **Координаты — не из первоисточника** (в xls их нет): прод-геокодер Фарпоста `<internal-geocoder-host>/<internal-geocoder-endpoint>`, только верифицированные совпадения конкретного дома (type=address, precision='exact'), покрытие 91,4 %; сырые ответы — fkr_geo.jsonl / fkr_geo2.jsonl. **Ограничение: координаты получены внутренним сервисом Фарпоста — публиковать их как «официальные координаты ФКР» нельзя.**
- Сборка CSV — агент «Вёрст» по заданию владельца (13.11.2026), скрипты и протокол — 03_sources/raw/fkr25/. В проекте CSV используется как есть: 05_code/houses_prep.py фильтрует Владивостокский ГО и гео «да» → 3 583 дома на карте (V3/V4).

## Сводные честные ограничения

1. year_source пуст у 77 линий из 821 (9,4 %); у 1 линии нет и года.
2. Классификация авторская: 45 «нужна проверка» в CSV / 44 линии в geojson на момент коммита V8 (до V5 было 85; −40 по итогам V2).
3. Координаты домов — геокодер Фарпоста (внутренний сервис), не «официальные координаты ФКР»; 8,6 % домов без координат.
4. Лицензии: геометрия — ODbL (© участники OpenStreetMap); у репозитория vvmap явной лицензии нет; на fkr25.ru и ginfo.ru явной лицензии нет (ФКР — приложение к нормативному акту, статус перепубликации не проверен).
5. Сырые страницы исследования V2 не сохранялись — только URL в вердиктах.
6. Даты получения ginfo/vvmap/классификации — по первому коммиту 13.11.2026 (время суток не фиксировалось); ФКР-цепочка датирована по протоколу Вёрста.
