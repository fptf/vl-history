## Происхождение по полям (ключевые наборы)

### 1. Год названия улицы
- **Значения года** (`streets_map.geojson` → properties.year; в данных карты поле `y`): из выгрузки открытого проекта **vvmap** (github.com/skirienko/vvmap), файл `02_data/vvmap_streets_years.csv` (колонки street;year;description;source). Внутри vvmap годы собраны из истории переименований: справочник 1924 г., список 1957 г., постановления администрации г. Владивостока и др.
- **Построчная ссылка на документ** — properties.year_source в streets_map.geojson (текст ссылки: постановления администрации/главы г. Владивостока с номерами и датами, «Упомянута в справочнике 1924 г.», «в списке 1957 г.», ссылки t.me/vvtopo, t.me/ochkuryvl, wikimapia и т.п.).
- **Ссылки на первоисточники в карточке улицы** (T-001, 15.11.2026; поле `src` в data.json → общий список `srcs`): из колонки `source` vvmap_streets_years.csv и текста year_source — тексты постановлений в репозитории vvmap (`documents/YYYYMMDD-N.md`, только при наличии в vvmap_documents.txt; распознаются и ссылки вида «от ДД.ММ.ГГГГ № N»), посты t.me/vvtopo и t.me/ochkuryvl, постановления topovl.ru (домен больше не резолвится — ссылка ведёт на снимок web.archive.org); плюс URL веб-исследования (`06_research/findings*.jsonl`, статус «опознан») и URL из примечаний вердиктов V5 (из текста примечания убраны). Покрытие: 348 из 821 линии. Проверка 15.11.2026: документы vvmap 36/36 и исследовательские URL — HTTP 200; t.me из сети проверки недоступен — посты сверены по снимкам Web Archive (кроме t.me/vvtopo/31: снимка нет); ru.ruwiki.ru отвечает 401 на автоматический запрос, kfss.ru — ошибка TLS (есть снимок Web Archive). «wikimapia» в vvmap — без ссылки, в карточку не выводится.
- **Местность улицы** (T-013, поле `l` в data.json): вычисляется prep.py по геометрии — острова по кольцам суши из береговой линии OSM (water.json), на материке по полю part (Песчаный, Трудовое, иначе город). Поле part в streets_map.geojson не исправлялось: у 28 линий оно расходится с геометрией (26 на о. Русском и 2 на о. Попова помечены mainland).
- **Контуры домов** (T-014): дом ФКР сопоставлен со зданием OSM по точке геокодера — контур, содержащий точку (3 580 из 3 583), иначе ближайший не дальше 25 м (3); 05_code/buildings_prep.py. Остальные здания OSM — серая подложка. Результат — отдельный файл 04_prototype/vladivostok-streets-map.buildings.js (2,5 МБ), карта подгружает его при включении слоя домов; без файла слой остаётся точками.
- **Честно:** из 821 линии year_source пуст у **77** (9,4 %); полностью без года — 1 линия. У скольких линий год отсутствует вовсе — см. сводку сборки prep.py.
- «Год постройки» дома — другое поле из ФКР-выгрузки (см. п. 4), к топонимике отношения не имеет.

### 2. Геометрия
- Линии улиц и точки мысов — **OpenStreetMap** через проект vvmap; условия: ODbL, атрибуция «© участники OpenStreetMap». У репозитория vvmap явной лицензии нет — перед публикацией уточнить у автора.
- Путь в проект: `02_data/vvmap_*.csv/geojson` → `02_data/streets_map.geojson` → `05_code/prep.py` → `05_code/data.json` → шаблон → HTML.

- **Справки из статей** (T-023, 20.11.2026; `06_research/articles.json` → поле `a` и список `arts` в data.json): статья VL.ru «От Багратиона до Уборевича: имена каких генералов носят улицы во Владивостоке», 12.12.2021, https://www.newsvl.ru/history/2021/12/12/204854/ — открыта и прочитана 20.11.2026 (HTTP 200). 19 улиц статьи сопоставлены с линиями карты по имени — все найдены (в статье «улица Острякова», на карте и в ginfo — проспект). Тексты справок — краткий пересказ статьи своими словами, без сведений со стороны; в карточке каждой справке сопутствует ссылка на статью. Страница статьи не сохранялась — проверяемость по URL. Расхождения: в самой статье у Шошина два отчества (Петрович / Николаевич) — взято «Петрович»; прежних названий и дат присвоения в статье нет, наши годы она не опровергает.

## Сводные честные ограничения

1. year_source пуст у 77 линий из 821 (9,4 %); у 1 линии нет и года.
2. Классификация авторская: 45 «нужна проверка» в CSV / 44 линии в geojson на момент коммита V8 (до V5 было 85; −40 по итогам V2).
3. Координаты домов — геокодер Фарпоста (внутренний сервис), не «официальные координаты ФКР»; 8,6 % домов без координат.
4. Лицензии: геометрия — ODbL (© участники OpenStreetMap); у репозитория vvmap явной лицензии нет; на fkr25.ru и ginfo.ru явной лицензии нет (ФКР — приложение к нормативному акту, статус перепубликации не проверен).
5. Сырые страницы исследования V2 не сохранялись — только URL в вердиктах.
6. Даты получения ginfo/vvmap/классификации — по первому коммиту 13.11.2026 (время суток не фиксировалось); ФКР-цепочка датирована по протоколу Вёрста.
