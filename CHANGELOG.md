## [14.11.2026] — рабочий цикл V1–V11 (ночь 13→14.11 VLK)

### Добавлено
- Плавное появление домов внутри десятилетия при «Показать рост» (`5b37b4f`): в такте анимации `cumulYear` больше не прыгает к концу десятилетия, а интерполируется непрерывно от начала к концу слота (rAF, слот 900 мс — длительность и поведение улиц как в V6/V9), поэтому дома десятилетия появляются постепенно, по своим годам постройки, в порядке строительства; счётчик «к YYYY г.» показывает точный год (1974, 1975…) и тикает вживую вместе со «новых за десятилетие» (подсчёт по точному `f.y`, на границе десятилетия совпадает с прежним счётом по `f.dec`); decade-stamp остаётся «1970-е», улицы/бары переключаются по границам слотов, дом без года — в самом конце анимации (фильтр `houseVisible` не менялся).
- Дома в проигрывании «Показать рост» (`053d9de`): во время анимации (и после паузы на любом десятилетии) слой домов показывает только дома с годом постройки ≤ конца текущего десятилетия, синхронно с decade-stamp (единый источник — `cumulTo` → `cumulYear`); дом без года появляется на финальном шаге; при выключенном тумблере дома не рисуются, вне анимации — все дома.
- Переключатель цвета домов «по году / по улице» в секции домов (`51c9455`): «по году» — прежняя сине-янтарная шкала по десятилетию; «по улице» — цвет точки = цвет группы улицы, к которой привязан дом (`h[5]` → `street_names` → улица карты → `var(--g{gi})`), без привязки — серый; легенда переключается между градиентом десятилетий и групповыми цветами со счётчиками домов; перерисовка мгновенная, групповые цвета берутся из CSS-переменных (темы живы).
- Слой домов «Дома (год постройки)» на карте — 3 583 многоквартирных дома ФКР Владивостокского ГО (`9e475cb`): canvas-слой с тумблером (выкл. по умолчанию), шкала «десятилетие постройки» (сине-янтарная) + легенда, клик по дому — адрес/год/материал/этажей, клик по улице — сводка по её домам (кол-во, мин–макс год, топ-3 материала). Скрипт `houses_prep.py` выдаёт год и полный адрес ФКР для каждого дома (append-only, 8 полей).
- Карта происхождения данных `03_sources/provenance.md` — источник/дата/лицензия/метод по каждому файлу (`02_data`, `buildings`, `06_research`, сырые выгрузки) и происхождение по полям: год и year_source (проект vvmap), геометрия (OSM, ODbL), классификация (авторская + 40 правок V5), дома (fkr25.ru + геокодер Фарпоста) (`6ecdb8e`).
