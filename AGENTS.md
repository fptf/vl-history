# Правила для агентов

Проект: «Топонимика улиц Владивостока» — офлайн-карта названий улиц + слой домов ФКР (один HTML-файл).
Этот файл читают все агенты (Claude Code, Codex и др.), работающие с репозиторием.

## Задачи — в `TASKS.md`

- **Перед работой** прочитай `TASKS.md`. Бери задачу из «Очереди» или ту, что поставил владелец; перенеси её в «В работе» с пометкой `@<агент>` и датой.
- **По ходу** дописывай в задачу короткие заметки: что выяснено, что решено, что блокирует. Это журнал для следующего агента — без воды, факты и пути к файлам.
- **После** перенеси задачу в «Готово» со ссылкой на коммит (короткий SHA) и одной строкой результата. Если не доделано — оставь в «В работе» с пометкой, где остановился.
- Новая обнаруженная проблема — новая строка в «Очереди», а не молчаливая правка.
- Формат задачи:
  ```
  - [ ] T-NNN Заголовок — @агент, ДД.ММ.ГГГГ
    - контекст / критерий готовности
    - заметка: …
  ```
  Номера `T-NNN` сквозные, не переиспользуются.

## Сборка и проверка

- Карта собирается из шаблона: `05_code/map_template.html.tpl` → `python3 05_code/assemble.py` (нужен `05_code/data.json`); полная пересборка — `bash 05_code/build.sh`.
- Правишь шаблон или данные — пересобери и закоммить оба файла: шаблон и `04_prototype/vladivostok-streets-map.html`.
- Изменения интерфейса проверяй в браузере (headless Chrome), а не только чтением кода; ограничение — HTML ≤ 800 КБ.

## Данные и происхождение

- Происхождение каждого файла — `03_sources/provenance.md`; сырые выгрузки сверяются по `03_sources/raw/SHA256SUMS`. Новый источник данных — запись в provenance.
- Внешние ссылки в данных — только проверенные (открыты и сверены), без «сконструированных» URL.

## Приватность

- В репозиторий не попадают: рабочие диалоги, ключи, внутренние домены/сервисы, ID сессий, личные пути. Внутреннее — плейсхолдерами (`<internal-…>`).
- Ничего не пушить без явной просьбы владельца.
